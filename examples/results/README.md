# Example raw results

Real output of the Stage 3 tools, regenerated by `python scripts/generate_example_results.py`.
They were produced **on loopback with the userspace impairment proxy** (no namespaces, no tc netem), so they demonstrate the
file formats and metric behaviour, not the performance of the Stage 2 topology. Absolute timestamps differ on every run.

| Scenario | Ground truth | What the metrics show |
|---|---|---|
| `example-loss-by-seq` | proxy drops seqs 5, 17, 18, 19, 40 of 100 | `lost_seqs` equals that list, 5 %, longest burst 3 |
| `example-delay-20ms` | 20 ms each way | RTT min ≈ 40.1 ms, OWD ≈ 20 ms (same boot_id) |
| `example-handoff-blackout` | both directions dark 1.0 s - 1.4 s; path delay 10 ms -> 30 ms | 40-packet burst, ~430 ms interruption, RTT 20 -> 60 ms |
| `example-sigkill-sender` | sender killed with SIGKILL | `run_status: incomplete`, `loss.exact: false`, warnings, nothing invented |
